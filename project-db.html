Real Estate DB 房产管理数据库 Base de Données Immobilière

SQLite SQL Data Modeling

This is a database for a real estate management system. It concerns owners, clients, agents, contracts, and requests. This project was carried out in collaboration with a classmate. It allowed me to reinforce my skills in data structure design and basic database development with SQLite. 这是一个用于房地产管理系统的数据库。它涉及业主、客户、代理商、合同和请求。该项目是与一名同学合作完成的。它让我巩固了数据结构设计和使用 SQLite 进行基础数据库开发的技能。 Il s'agit d'une base de données pour un système de gestion immobilière. Elle concerne les propriétaires, les clients, les agents, les contrats et les demandes. Ce projet a été réalisé en collaboration avec un camarade de classe. Il m’a permis de renforcer mes compétences en conception de structures de données et en développement de bases de données basiques avec SQLite.

Technical Highlights 技术亮点 Points Techniques

  • Relational Schema Design. 关系型模式设计。 Conception de Schéma Relationnel.
  • Complex SQL Queries. 复杂 SQL 查询。 Requêtes SQL complexes.
  • Data Integrity constraints. 数据完整性约束。 Contraintes d'intégrité des données.
