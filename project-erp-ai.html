During my full-stack AI internship at Fuzhou Shangbo Software Co., Ltd., I developed AI features for an existing pharmacy and retail ERP. Working directly with the company director, I translated business needs into three modules: store diagnostics, price recommendations and an AI customer-support agent. 在福州商搏软件有限公司担任全栈 AI 开发实习生期间，我为现有药店及零售 ERP 开发 AI 功能。我直接与企业负责人沟通需求，围绕门店经营诊断、价格推荐和 AI Agent 客服三个模块完成开发。 Pendant mon stage de développement full-stack IA chez Fuzhou Shangbo Software Co., Ltd., j’ai développé des fonctionnalités IA pour un ERP existant destiné aux pharmacies et aux commerces. En lien direct avec le dirigeant, j’ai traduit les besoins métier en trois modules : diagnostic de magasin, recommandation de prix et agent IA de support client.

Three business modules 三个业务模块 Trois modules métier

  • Store diagnostics — Import ERP exports, including archives, or retrieve data through APIs. Explore heterogeneous files, structure tabular data and calculate indicators. Produce a detailed Markdown report and concise JSON diagnostic cards linking findings to evidence and suggested actions. 门店经营诊断——导入 ERP 导出文件（含压缩包）或通过 API 获取数据；探索异构文件、整理表格并计算指标，输出完整 Markdown 报告与 JSON 诊断卡片，将问题、数据依据和改进建议关联起来。 Diagnostic de magasin — Importer des exports ERP, y compris des archives, ou récupérer des données par API. Explorer les fichiers hétérogènes, structurer les tables et calculer les indicateurs. Produire un rapport Markdown et des cartes JSON associant constats, preuves et pistes d’action.
  • Price recommendations — Check input suitability, align product and sales data, and prepare price–volume observations. Python calculates revenue and, when purchase cost is available, profit; the interface presents charts and structured recommendations. In the current public implementation, candidates are ranked from normalized observations, rather than establishing a universally optimal price. 价格推荐——预检文件是否可用，对齐商品与销售数据，整理价格—销量观测点。由 Python 计算销售额，并在有进货成本时计算利润；界面展示图表与结构化建议。当前公开实现基于归一化观测点排序候选价格，推荐结果不代表普遍适用的最优售价。 Recommandation de prix — Vérifier les fichiers, rapprocher les données produit et ventes, puis préparer les observations prix-volume. Python calcule le chiffre d’affaires et, si le coût d’achat est connu, le profit ; l’interface affiche graphiques et recommandations structurées. L’implémentation publique actuelle classe les candidats à partir des observations normalisées, sans établir un prix universellement optimal.
  • AI customer support — Combine conversation history, user-provided files and controlled access to service documentation. Use tools and ERP APIs to assist with tasks such as preparing data imports from a previous ERP. Account-level file spaces and scoped service authorization frame access and actions. AI Agent 客服——结合会话历史、用户上传文件与受控的服务文档访问，通过工具和 ERP API 辅助处理业务任务，例如准备旧 ERP 数据导入。以账号文件空间及范围受限的服务授权约束数据访问与操作。 Agent IA de support — Combiner historique de conversation, fichiers utilisateur et accès contrôlé à la documentation de service. Utiliser des outils et les API ERP pour accompagner des tâches comme la préparation d’imports depuis un ancien ERP. Les espaces de fichiers par compte et les autorisations de service limitées encadrent les accès et les actions.

System architecture 系统架构 Architecture du système

  • Web interface & API — The browser uploads files, starts jobs and retrieves results through FastAPI. Long-running jobs expose status and SSE progress logs, with history and cancellation controls. Web 界面与 API——浏览器通过 FastAPI 上传文件、启动任务并获取结果。长任务提供状态与 SSE 进度日志，配套历史记录及取消操作。 Interface web et API — Le navigateur transmet les fichiers, lance les tâches et récupère les résultats via FastAPI. Les traitements longs exposent un état et des logs de progression SSE, avec historique et arrêt possible.
  • Agent orchestration — A custom AgentLoop uses the OpenAI SDK and configurable compatible model endpoints. It coordinates tool calls and a work plan inside a run workspace, separating input files, intermediate artifacts and outputs. Agent 编排——自定义 AgentLoop 通过 OpenAI SDK 连接可配置的兼容模型接口，在单次运行的 workspace 内组织工具调用与工作计划，并区分输入、处理中间产物与输出。 Orchestration de l’agent — Une boucle AgentLoop spécifique utilise le SDK OpenAI et des points d’accès compatibles configurables. Elle coordonne appels d’outils et plan de travail dans un workspace par exécution, séparant entrées, fichiers intermédiaires et sorties.
  • Data & delivery — Python, Pandas and DuckDB support file processing and analytical work. Structured JSON connects backend outputs to the UI; Linux, Uvicorn, systemd and Nginx support deployment. GitHub-based update automation forms part of the operational workflow. 数据处理与交付——使用 Python、Pandas 和 DuckDB 处理文件与分析数据，以结构化 JSON 对接前后端；通过 Linux、Uvicorn、systemd 和 Nginx 部署，并参与基于 GitHub 的自动更新流程。 Données et livraison — Python, Pandas et DuckDB servent au traitement des fichiers et à l’analyse. Des sorties JSON relient backend et interface ; Linux, Uvicorn, systemd et Nginx assurent le déploiement. Une mise à jour automatisée depuis GitHub complète l’exploitation.

Ajout de l’historique, des logs de progression et des vues de résultats structurées.

Engineering lessons & limits 工程思考与局限 Enseignements et limites

I learned to keep numerical calculations and access checks in program code, while using the language model to interpret files and explain results. Heterogeneous exports required exploration before processing and explicit output contracts. Price recommendations remain a decision-support prototype: sparse observations, promotions and data quality limit confidence. Deployment does not establish measured business impact. 我学会将数值计算与访问检查交给程序实现，让语言模型负责理解文件和解释结果。面对格式不一的导出文件，需要先探索结构，再处理数据，并约定明确的输出格式。价格推荐仍是辅助决策原型，观测点不足、促销和数据质量都会限制可信度；完成部署也不等于已经验证业务收益。 J’ai appris à confier les calculs numériques et les contrôles d’accès au programme, en utilisant le modèle pour interpréter les fichiers et expliquer les résultats. Les exports hétérogènes nécessitent une exploration préalable et des contrats de sortie explicites. La recommandation de prix reste un prototype d’aide à la décision : peu d’observations, les promotions et la qualité des données limitent sa fiabilité. Le déploiement ne démontre pas un impact métier mesuré.
