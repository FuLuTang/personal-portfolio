J'ai construit une application multiplateforme en Python 3.7+ avec une GUI Tkinter. L'outil dispose d'une architecture modulaire et du multithreading. Il gère divers formats de sous-titres (JSON, SRT, LRC) et intègre des API IA pour le traitement texte/audio.

## Fonctionnalités

- Multithreading pour une interface fluide.
- Support des formats JSON, SRT, LRC.
- Intégration IA (Texte/Audio).
