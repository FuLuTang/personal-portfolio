I built a multi-platform application in Python 3.7+ using Tkinter GUI. The tool features modular architecture and multithreading. It handles various subtitle formats (JSON, SRT, LRC) and integrates AI APIs for text and audio processing.

## Features

- Multithreading for smooth UI.
- Support for JSON, SRT, LRC.
- AI Integration (Text/Audio).
