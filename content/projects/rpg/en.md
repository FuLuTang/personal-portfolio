This is a 2D pixel art game, developed in C++. It uses SDL2 and SDL_image as base libraries for the game engine. This project was realized alone. The map and characters are managed using a position dictionary and a sprite image table. I implemented character animations, enemy logic, defeat and victory conditions, as well as a dynamic camera that automatically follows the player. This project allowed me to understand the basics of graphic rendering, the logic of a simple game engine, and develop my skills in game logic programming.

## Key Features

- Custom Rendering Engine with SDL2.
- Enemy AI with state machines.
- Dynamic Camera System.
