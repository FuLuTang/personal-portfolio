# personal-portfolio

个人作品集网站 —— 唐颢宸（Haochen TANG），计算机科学 / 开发者。

纯静态站点（原生 HTML / CSS / JavaScript，无框架、无构建步骤），直接部署在 GitHub Pages。

线上地址：<https://fulutang.github.io/personal-portfolio/>

## 设计

全站共用一套设计系统：**暖奶油底色 + 白色格子 + 森林绿主色 + 琥珀点缀**，浅色 / 深色两套主题。

- **首页**采用 Bento 格子矩阵：不等尺寸格子承载姓名、简介、教育、语言、技能、抱负、兴趣、联系方式与项目墙，首屏即可读完全部核心信息。项目截图以 `contain` 完整呈现，不做裁切。
- **项目详情页**采用统一模板：细工具条 + 森林绿 Hero 块（分类 / 标题 / 技术栈）+ 两栏正文（左述内容、右项目信息卡）+ 自适应画廊网格（按图片数量自动分列）。无截图的条目使用斜纹排版占位，不伪造素材。

设计 token 集中在 `css/bento.css` 顶部（`:root` 与 `[data-theme="dark"]`），详情页布局在 `css/detail.css`：

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面底色 | `#FAF7F2` | `#14120E` |
| 格子面 | `#FFFFFF` | `#1C1917` |
| 主色（森林绿） | `#1F6F5C` | `#4FAE93` |
| 点缀（琥珀） | `#D97706` | `#E8A03C` |
| 正文 | `#1C1917` | `#F4EFE7` |
| 次要文字 | `#78716C` | `#B4ADA6` |

## 功能

- **三语切换** —— 英语 / 中文 / 法语，切换时同步更新 `<html lang>` 与浏览器标签标题，选择写入 `localStorage`
- **明暗主题** —— 默认跟随系统偏好，可手动切换并持久化（首页与详情页共用同一套状态）
- **项目筛选** —— 首页全部 / 校内 / 个人，基于 `data-category` + CSS class，无框架依赖
- **响应式** —— 桌面 4 列格子矩阵与两栏详情页 → 平板 2 列 → 手机单列；全断点无横向溢出
- **无障碍** —— 键盘焦点可见（`:focus-visible`）、图片带语义 `alt`、`prefers-reduced-motion` 降级、跳转正文链接

## 目录结构

```text
index.html          首页（Bento 格子矩阵）
project-*.html      8 个项目详情页（统一模板：Hero + 两栏 + 画廊）
css/bento.css       设计 token + 工具条 + 首页格子样式
css/detail.css      详情页布局（Hero / 两栏 / 画廊网格 / 无图占位）
js/lang.js          多语言切换
js/theme.js         明暗主题切换
js/filter.js        首页项目分类筛选
assets/             项目截图与素材
```
