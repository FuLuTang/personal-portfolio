VRCX-jirai est une branche modifiée de l'assistant VRCX pour VRChat, conçue pour améliorer la visualisation des données sociales et le suivi des relations.

## Fonctionnalités Clés

- **Requête de relation entre deux personnes :** Analyse chaque instance où deux amis étaient dans la même pièce.
- **Vue Bio Diff :** Interface de style Git pour suivre les modifications des biographies.
- **Amélioration du graphe d'amis mutuels.**
- **Graphiques de distribution d'état.**
