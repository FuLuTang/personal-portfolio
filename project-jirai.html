VRCX-jirai Edition VRCX 优化版 - 地雷Edition VRCX-jirai Edition

Electron SQLite Social Analytics VRChat

VRCX-jirai is a modified branch of the popular VRChat assistant VRCX, specifically designed to enhance social data visualization and relationship tracking. It aims to provide deep insights into co-presence history and social dynamics within the VRChat community. VRCX-jirai 是著名 VRChat 辅助软件 VRCX 的魔改分支，专为增强社交数据可视化和关系追踪而设计。该版本旨在深入挖掘用户间的共存历史，并直观展示社交圈态势。 VRCX-jirai est une branche modifiée de l'assistant VRCX pour VRChat, conçue pour améliorer la visualisation des données sociales et le suivi des relations.

Key Features 核心功能 Fonctionnalités Clés

  • Two-Person Relationship Query: Analyze every instance where two selected friends were in the same room. 双人关系查询： 一键分析任意两个好友共同处于同一房间的详尽历史。 Requête de relation entre deux personnes : Analyse chaque instance où deux amis étaient dans la même pièce.
  • Bio Diff View: Git-style interface to track changes in user biographies over time. 简介差异追踪： 类似 Git Diff 的界面，实时捕捉好友简介的细微变动。 Vue Bio Diff : Interface de style Git pour suivre les modifications des biographies.
  • Mutual Friend Graph Enhancement: Better visualization and manual connection management for social circles. 关系网增强： 优化的共同好友关系图，支持手动标记隐藏关系。 Amélioration du graphe d'amis mutuels.
  • Status Distribution Charts: Visual breakdown of online time spent in various statuses (Green/Blue/Yellow/Red). 灯色时长统计： 直观统计并展示用户在线期间各种灯色的时间占比分布。 Graphiques de distribution d'état.
