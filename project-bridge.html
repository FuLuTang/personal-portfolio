Bridge Bidding Assistant 桥牌叫牌辅助系统 Assistant d'Enchères au Bridge

Vue 3 Vite LLM Agent Team of 9

University team project (9 students) building a bridge bidding assistant. I was the front-end lead. 大学团队项目（9 人），开发桥牌叫牌辅助系统。我担任前端负责人。 Projet universitaire en équipe (9 étudiants) : un assistant d'enchères au bridge. J'étais responsable du front-end.

My Contributions 我的工作 Mes Contributions

  • Set up the front-end base with Vue 3 + Vite. 使用 Vue 3 + Vite 搭建前端基础架构。 Mise en place de la base front-end en Vue 3 + Vite.
  • Defined the deal JSON format together with the backend team. 与后端共同约定牌局（deal）JSON 数据格式。 Définition du format JSON des donnes avec l'équipe backend.
  • Front/back integration and merging of the team's work. 负责前后端联调与代码合并。 Intégration front/back et fusion du travail de l'équipe.
  • Integration of an LLM agent into the application. 在应用中接入 LLM Agent。 Intégration d'un agent LLM dans l'application.
