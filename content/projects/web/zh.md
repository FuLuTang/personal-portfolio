小组合作创建一个旅游网站，使用 HTML 和 CSS。我们在两名同学的协作下完成了这个项目。我主要负责“联系我们”页面、全局 CSS 样式以及导航栏和页脚的设计。该网站具有响应式设计，能够动态适应不同的窗口大小，并已通过 W3C 认证。该项目让我巩固了 HTML 开发基础和 CSS 排版技能，并了解了网站上线的流程。

## 主要方面

- 响应式设计（移动优先）。
- 符合 W3C 标准。
- 语义化 HTML 结构。
