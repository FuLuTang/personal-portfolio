Subtitle Tool 字幕处理工具 Outil de Traitement de Sous-titres

Python Tkinter AI API

I built a multi-platform application in Python 3.7+ using Tkinter GUI. The tool features modular architecture and multithreading. It handles various subtitle formats (JSON, SRT, LRC) and integrates AI APIs for text and audio processing. 我使用 Python 3.7+ 和 Tkinter GUI 构建了一个多平台应用程序。该工具采用模块化架构和多线程技术。它支持多种字幕格式（JSON, SRT, LRC）并集成了用于文本和音频处理的 AI API。 J'ai construit une application multiplateforme en Python 3.7+ avec une GUI Tkinter. L'outil dispose d'une architecture modulaire et du multithreading. Il gère divers formats de sous-titres (JSON, SRT, LRC) et intègre des API IA pour le traitement texte/audio.

Features 功能 Fonctionnalités

  • Multithreading for smooth UI. 多线程保证界面流畅。 Multithreading pour une interface fluide.
  • Support for JSON, SRT, LRC. 支持 JSON, SRT, LRC 格式。 Support des formats JSON, SRT, LRC.
  • AI Integration (Text/Audio). AI 集成（文本/音频）。 Intégration IA (Texte/Audio).
